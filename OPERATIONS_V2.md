# Операционные функции «Земельного Штурмана» — версия 2

## Сделано сейчас

### Разбор PDF/DOCX

- Пользователь загружает PDF или DOCX до 4 МБ и выбирает тип: отказ, ПЗЗ или другой земельный документ.
- Файл не сохраняется в приложении. Сервер извлекает текст только для одного запроса и передаёт его AI для разбора.
- PDF должен содержать текстовый слой; скан без распознанного текста честно возвращает подсказку.
- Перед отправкой пользователь подтверждает передачу текста AI-провайдеру.

### Заявления

- Доступны черновики для сформированного участка, несформированного участка и утверждения СРЗУ.
- В основу положены переданные учебные шаблоны.
- Черновик можно скопировать или скачать как TXT. Перед подачей пользователь обязан проверить адресата, правовое основание и приложения.

### Напоминания

- Можно сохранить текст и дату напоминания в браузере.
- При открытом сайте Штурман показывает просроченное напоминание; по желанию использует уведомление браузера.
- Данные остаются только на устройстве пользователя.

### Проверка участка

- По кадастровому номеру Штурман пытается получить кадастровую стоимость и ведёт к официальной проверке на НСПД, ГИС Торги и Росреестре.

## Что требует отдельного доступа перед включением

Автоматический поиск свободных участков и непрерывный мониторинг новых торгов нельзя добросовестно включить без разрешённого источника данных и фонового сервиса. НСПД блокирует часть серверных обращений, а ГИС Торги не даёт в проекте подтверждённый стабильный открытый поток для такого поиска.

Для полноценного режима нужны:

1. выбранный законный поставщик данных или официальный API;
2. российский сервер, если доступ НСПД ограничивается по IP;
3. канал доставки уведомлений — Telegram-бот или email-сервис — и согласие пользователя на уведомления;
4. база данных для сохранения поисков, лотов и напоминаний между устройствами.

До подключения этих компонентов приложение не называет найденный участок «свободным» и не обещает, что торг ещё актуален.
