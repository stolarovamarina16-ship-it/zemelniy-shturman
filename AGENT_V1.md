# Земельный Штурман — агент, версия 1

## Что изменилось

Главный вход теперь не анкета. Пользователь описывает задачу обычными словами, а Штурман:

1. даёт один ближайший шаг;
2. раскладывает последующие действия по порядку;
3. напоминает, что необходимо проверить до заявления или торгов;
4. задаёт только один действительно нужный уточняющий вопрос;
5. сохраняет контекст последних реплик в рамках открытого диалога.

Старое короткое интервью не удалено: оно доступно как запасной путь для человека, который не знает, с чего начать.

## Какая база уже подключена

- 11 сценариев получения земли из `app/js/strategies.js`;
- ставки выкупа из `app/js/region-data.js` для 83 регионов;
- калькулятор выкупа и кабинет проверки участка, добавленные ранее.

Ответ называет ставку только когда пользователь указал регион. Справочник датирован июнем 2026 года, поэтому перед подачей Штурман предупреждает о необходимости сверить актуальный региональный акт.

## Честные границы версии 1

Штурман не имитирует доступ к Росреестру, НСПД или ГИС Торги. Он направляет к официальным источникам для живой проверки статуса участка и публикаций. Это защищает пользователя от выдуманных «свободных участков» и несуществующих торгов.

В исходном репозитории нет самой библиотеки из 90+ PDF/DOCX. Поэтому в эту версию вошли только те данные, которые физически лежат в проекте: 11 стратегий и 83 региональные ставки. Когда папка с документами будет добавлена в репозиторий или передана отдельно, следующий этап — поиск по этим материалам с указанием документа-источника в каждом ответе.

## Следующий этап

1. Передать или добавить в репозиторий папку с PDF/DOCX-базой.
2. Разобрать документы на фрагменты и подключить поиск по ним.
3. Добавить интеграции с официальными источниками там, где они допускают стабильный и законный доступ.
4. Сделать «карточку дела»: цель, участок, список проверок, документы и сроки пользователя.
