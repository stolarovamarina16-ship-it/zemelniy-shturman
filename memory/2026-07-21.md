## Решение по AI-модели для этапа 4 (подключение AI)
Марина спросила какую модель ставить через Polza.ai (агрегатор, ключ POLZA_API_KEY уже
в переменных, но баланс 0₽ — 402 при тестовом запросе, ключ рабочий).
Решение: Claude Haiku 4.5 (anthropic/claude-haiku-4.5) как основная модель для чата —
дёшево (~0,5₽/вопрос с базой знаний в контексте), 200k контекста, хорошо держит рамки
"отвечай только по базе знаний, скажи не знаю если вне темы". Claude Sonnet 4.5
(anthropic/claude-sonnet-4.5) — апгрейд для этапа 5 (генерация текста заявлений),
там точность формулировок важнее, ~1,5₽/запрос.
Проверил в живую через API каталог моделей Polza — ни одна модель (включая GigaChat/
YandexGPT) не помечена fz152-compliant/ru_data, так что довод "отечественное = надёжнее
по 152-ФЗ" не подтвердился, можно не учитывать при выборе.
Открытый вопрос: пополнить баланс Polza, чтобы протестировать реальный вызов (пока была
502 на пустом балансе — только сама авторизация проверена, генерация нет).

## Этап 4 реализован: AI-ответы подключены (Claude Haiku 4.5 через Polza.ai)
Баланс Polza пополнен — тестовый запрос прошёл с HTTP 200 (реальная генерация, cost_rub
в ответе). Собрал полную интеграцию:
- app/api/ask.js — новый серверный хендлер (Vercel/Express-совместимый, как cadastre.js).
  POST {question} → системный промпт с базой всех 11 стратегий + инструкция отвечать
  только по теме земли и честно говорить "не знаю" вне базы. Модель anthropic/claude-haiku-4.5,
  ключ POLZA_API_KEY читается из process.env (в браузер не попадает).
- app/js/strategies.js — добавлен module.exports в конце файла, чтобы Node мог
  переиспользовать те же данные без дублирования (браузер не затронут).
- app/server.js — добавлены express.json() и POST /api/ask.
- app/js/app.js — поле "Задайте вопрос" в handleSend() теперь реально дёргает /api/ask
  вместо заглушки; при ошибке сети/сервера — вежливый фолбэк-текст, кнопка блокируется
  на время запроса.
Проверено локально (node server.js на порту 3055 + curl): вопрос по теме (ЗОУИТ) —
развёрнутый корректный ответ; вопрос не по теме (курс доллара) — модель честно
отказалась и вернула к теме земли; пустой вопрос — 400; статика по-прежнему отдаётся.
Коммит запушен в origin/main → должен подхватиться автодеплоем на Vercel. Для реальной
работы на проде нужно доложить POLZA_API_KEY в переменные окружения Vercel-проекта
(иначе будет 500 no_api_key) — и отдельно обновить деплой на Beget VPS (там ручной
tar+scp+pm2 restart, плюс свой .env с ключом).
